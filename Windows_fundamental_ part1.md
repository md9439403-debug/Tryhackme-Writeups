---

## 🔑 Key Concepts & Notes

1. **Windows Editions:** Different versions of Windows tailored for home users, enterprises, and servers (e.g., Windows Home, Pro, Enterprise).
2. **NTFS File System:** The standard file system used by modern Windows versions supporting security permissions and file compression.
3. **User Account Control (UAC):** A security feature that helps prevent unauthorized changes to the operating system by asking for permission or administrator credentials.
4. **Task Manager:** A built-in system monitor tool used to check performance, manage running processes, and stop unresponsive applications.

## 🛠️ Tools & System Components

| Component / Utility | Usage / Example | Description  |
| --- | --- | --- |
| Desktop GUI | Graphical Interface | Visual interface to interact with files, folders, and applications |
| File Explorer | `Win + E` | File management tool to navigate the Windows file system |
| System32 Directory | `C:\Windows\System32` | Contains core operating system files and system binaries |
| UAC Prompt | Administrator popup | Notifies users and requests elevation before running system-level tasks |
| Control Panel / Settings | Configuration hub | Centralized location to manage system settings, hardware, and networks |
| Task Manager | `Ctrl + Shift + Esc` | Monitors resource usage (CPU, Memory) and manages background processes |
